# FirePort

Gerenciador de Rede Neutra para ERP Hubsoft feito em TypeScript com IA.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` no navegador.

## Produção

Use o pacote aaPanel:

```bash
npm run pack:aapanel
```

As instruções de deploy ficam em `doc/deploy-aapanel.md`.
